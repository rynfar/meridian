## Review findings

1. **Reference text named a tool that cannot be called (corrected).** In client-search mode the PR rendered `tool_reference` blocks as text under the client's name (`[Tool reference: mcp__ledger__ledger_update]`), while only `mcp__oc__mcp__ledger__ledger_update` is registered. A model that copies the name it sees makes the inner CLI refuse the call: the turn ends with `Reached maximum number of turns (1)`, Meridian returns HTTP 500, and Claude Code retries about 10 times and exits 1. Reproduced with a scripted upstream that copies the reference text verbatim. The streamed bare-name recovery does not catch it (a non-`mcp__oc__` `mcp__*` name is skipped as internal). This is the #1107 failure class.
2. Acceptable, documented in the PR's SPEC.md change: each newly discovered tool changes the registered tool set, so that turn re-primes the prompt cache (main also rebuilt on that turn).
3. Acceptable, docs follow-up: `clientOwnsToolSearch` (`passthroughTools.ts`) detects Claude Code's convention by request shape (at least one `defer_loading` tool plus a loaded tool named exactly `ToolSearch`). A client merely sending a tool named `ToolSearch` is unaffected, and shape detection also covers Claude Code traffic resolved to another adapter. It is marked `NOTE: agent-specific`; ARCHITECTURE.md's agent-specific table (currently titled for OpenCode) does not list it.
4. Safe: the defer pin is an in-memory LRU, never persisted, so a restart clears old-meaning pins; a client deferring its own tools now ignores the pin and is never auto-deferred.
5. No change for other clients: for OpenCode-shaped requests the tools array the inner CLI sends upstream has an identical digest on main and head (10 and 20 tools, streaming and non-streaming, two turns); auto-defer still applies (`deferred=14/20`); the cache-key string is session-stable.
6. Minor: in client-search mode the deferred count and discovered-tool telemetry stay empty, since the client does its own discovery.
7. Tests: every new test except two regression guards fails on main.
8. Pre-existing, not from this PR: with auto-defer on and a client-sent `ToolSearch` that is not deferred, a prefix-stripped stream event named `ToolSearch` can still be filtered as internal.
