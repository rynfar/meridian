## Review findings

1. **The #1352 Home Manager environment harness broke (corrected).** The module's outer argument changed from a package set to `{ self }`; `scripts/e2e-home-manager-env.py` still called it with `{ meridian = …; }` and failed with "called without required argument 'self'".
2. **The manual `nix-update` command named `legacyPackages.x86_64-linux…` (corrected).** On any other system it fails prefetching with "platform mismatch", including the owner's aarch64-darwin Mac. The workflow itself runs on x86_64 and is fine.
3. **E2E.md still pointed Nix plugin builds at `lib/index.js` (corrected).** It now names `.path` (`lib/node_modules/@rynfar/<pname>/dist/index.js`); nothing else in the repository used the old path.
4. **Owner decision:** `packages.<system>.meridian` now needs `NIXPKGS_ALLOW_UNFREE=1 … --impure` (also for `nix run` and `nix profile install`). `docs/deployment.md` documents it as Option B but still offers it for system configurations, where every rebuild would have to be impure.
5. **Recommended, not committed:** `nix/pkgs/claude-code/package.nix` reads `claude-code.src.url` before the version check, so a consumer `claude-code` that meets the floor but has no `src` (for example a `symlinkJoin` wrapper) fails with "attribute 'src' missing". Comparing against `(importJSON ./manifest.json).version` first fixes it without changing the other scenarios.
6. Acceptable: on nixos-25.11 (past end of life) the `claude-code` package lacks a `manifest` argument, so the overlay fails there.
7. **Owner decision:** `refactor` is hidden in `release-please-config.json`, so under the PR's title none of the consumer-facing changes reach the release notes.
8. Checked with no defect: no `pull_request_target`; no `repository_dispatch` input reaches a `run:` step; `update-plugins` commits only `nix/pkgs/meridianPlugins`; the default token is read-only; actions are tag-pinned as on main; consumers still overriding a removed `meridian-plugin-*` input get only a warning; `legacyPackages` keeps its shape; no spec or API contract treats the flake outputs as stable; the AGENTS.md edit is accurate.
