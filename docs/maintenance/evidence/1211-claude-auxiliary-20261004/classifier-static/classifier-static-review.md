## Discriminating controls

Reject ordinary first-turn XML and a three-turn XML conversation with the same session key, absent tools and `</block>` stop. Reject the complete prefix/envelope quoted only in user text; markers in ordinary system text without the classifier opening; opening without a complete pair; reversed/missing/partial tags; and markers split between system blocks. Keep the incompatible supplied-stop/tools/stream negatives, including unknown, null, empty, malformed and mixed stop values. Positive synthetic controls should include an official-shaped classifier text block after a separate billing block, both known stops, omitted stop for stage2/fast, stream omitted, and a segmented transcript with more than two user messages.

Do not cap the message count: the official I1o segmented mode creates one user message per transcript block, with optional leading context. A short all-user body is not classifier evidence either.
